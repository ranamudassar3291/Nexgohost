#### B. The Client Reseller Dashboard Integration (`/dashboard/reseller`)

1. Tab 1: Credit Balance & Ledger ("Credit Add System")

3. Tab 3: API Credentials & Live Web-Dev Tools

#### C. The Master Admin Administration Dashboard (`/admin/resellers`)

Saving changes must instantly update the `reseller_domain_pricing` database table and refresh the public pricing comparison layout dynamically.
- Account Balance Manual Override Panel: A utility component letting the admin look up any reseller's email and manually append or debit funds to handle transaction errors or custom balances securely.

### 3. DATABASE RELATIONAL SCHEMA & DATA INTELLIGENCE
Generate and apply clean, optimized PostgreSQL DDL execution blocks for the following structural schemas:
1. `reseller_profiles`: `id` (PK), `user_id` (FK), `business_name`, `status` ('pending', 'active', 'suspended'), `api_key` (Unique Hash), `discount_slab_tier` (1, 2, or 3), `created_at`.
2. `reseller_funds`: `id` (PK), `user_id` (FK), `balance` (DECIMAL 10,2 DEFAULT 0.00), `currency` (DEFAULT 'USD'), `updated_at`.
3. `reseller_domain_pricing`: `id` (PK), `tld` (VARCHAR, e.g., '.com'), `retail_price` (DECIMAL 10,2), `reseller_price` (DECIMAL 10,2).
4. `reseller_orders`: `id` (PK), `user_id` (FK), `domain_name`, `action_type` ('register', 'transfer', 'renew'), `cost` (DECIMAL 10,2), `status` ('completed', 'failed', 'processing'), `created_at`.
